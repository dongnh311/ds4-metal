## Quicksort Explanation

Quicksort is a divide-and-conquer sorting algorithm. It works by:

1. Choosing a **pivot** element from the array.
2. Partitioning the array into three parts:
   - Elements less than the pivot
   - The pivot itself
   - Elements greater than the pivot
3. Recursively sorting the “less than” and “greater than” parts.
4. Combining the results.

A simple Python implementation is not fully in-place, but it is clear and easy to understand.

## Python Implementation

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]

    left = [x for x in arr if x < pivot]
